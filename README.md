# Digital Banking Backend

A backend banking system built with Spring Boot.  
This project includes core banking features such as user management, account creation, and money transfers.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Lombok
- Swagger / OpenAPI

## Features
- User registration
- User validation
- Account creation
- View account details
- Money transfer between accounts
- Transaction history

## Project Structure
- controller — API endpoints
- service — business logic
- repository — database layer
- entity — database models
